# Token Atlas 0.5.3

- 支持直接流式读取 Codex `.jsonl.zst` 冷存储会话，完整统计历史用量并保留分叉去重。
- 未变化的压缩文件复用会话元数据与调用缓存，刷新时跳过重新打开和解压。
- 明文会话转为压缩格式时，校验缓存前缀摘要并保留已有用量与去重状态；追加内容仅解析新增字节，历史内容改变时安全重建。
- 同路径同时存在 `.jsonl` 与 `.jsonl.zst` 时，优先使用明文版本，仅统计一次。
- Python 3.14 使用内置 Zstandard 读取器；较早版本使用已安装的 `zstd` 命令。

验证：54 项 Python 回归测试及自检通过；系统 Python 下的 10 项压缩会话回退测试通过。
