# Token Atlas 0.5.4

0.5.4 为顶部栏实时统计弹窗加入 Codex、Claude 和 Antigravity 账户额度，并提供独立显示开关、组件排序与持久化配置。

- 查看三家账户的剩余额度和重置时间。Codex 按实际返回的额度窗口展示；Antigravity 摘要显示最低剩余百分比，各模型明细可在限定高度内滚动查看。
- 在主窗口齿轮菜单 →「顶部栏组件…」中，独立显示或隐藏各家额度，通过原生列表拖动调整实时统计整体组件与额度组件的顺序。配置跨重启保存，隐藏额度组件后暂停对应查询，弹窗高度随内容调整。
- 实时统计包含来源选择、累计用量、60 秒平均 Token/s、曲线、INPUT / CACHE / OUTPUT 明细，以及 1 / 2 / 5 秒刷新设置。卡片顶部提供拖动手柄。

使用条件：

- **Codex**：本机 Codex CLI 已登录。
- **Claude**：点击「连接」并确认配置本地 Claude Code 状态栏桥接脚本。受支持的官方额度数据随后续模型响应更新，已有状态栏输出继续转发。
- **Antigravity**：本机应用正在运行且已登录。额度查询使用该应用内部的本地服务接口，兼容性可能随应用版本变化。

会话统计继续在本机进行。
