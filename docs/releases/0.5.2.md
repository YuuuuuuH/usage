# Token Atlas 0.5.2

Token Atlas 将 Codex、Qodex 和 Claude 的本机用量汇总到「全部」视图，支持 macOS 12 及以上版本的 Apple Silicon 与 Intel Mac。

- 默认总览合并可用数据源；Claude 使用完整的统计、会话、价格和审计界面。
- 读取 Claude Code 与 Claude 桌面应用的本机 JSONL 记录，去重消息快照，并统计缓存读取、缓存创建与输出用量。
- 补齐 GPT-6.1 Sol 等模型的官方价值估算，按 Default、Priority/Fast 和长上下文规则计价；模型价格表同时展示 Token 用量。
- 模型分布和高用量日期每页显示 10 条，会话每页显示 20 条，翻页控件位于表格上方。
- 应用运行时每 10 分钟自动刷新；Codex 用量刷新复用增量解析缓存。
- 成就扩展至 19 条，按使用习惯、模型探索、协作足迹和 Token 里程碑分组。钻石及更高等级达成后揭示；紧凑勋章卡片突出当前纪录与达成日期。
- 升级沿用现有应用标识与缓存位置，保留配置与统计历史。

验证：44 项 Python 回归测试、原生组件测试、完整应用冒烟检查，以及浅色和深色成就界面检查均通过。安装包为 Universal macOS DMG，附 SHA-256 校验文件。
